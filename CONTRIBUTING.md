# Contributing to Encor

First off, thank you for considering contributing to Encor! It's people like you that make open source such a great community.

## How to Contribute

1. **Fork the repository** on GitHub.
2. **Clone your fork** locally: `git clone https://github.com/YOUR-USERNAME/encor.git`
3. **Create a branch** for your feature or bugfix: `git checkout -b feature/your-feature-name`
4. **Make your changes** and test them thoroughly. Make sure to follow the existing code style (Black for Python, clean CSS for frontend).
5. **Commit your changes**: `git commit -m 'Add some feature'`
6. **Push to the branch**: `git push origin feature/your-feature-name`
7. **Submit a Pull Request** to the `main` branch of the `rayzien/encor` repository.

## Development Setup

To set up the development environment:
1. Ensure Python 3.10+ is installed.
2. Run `pip install -r requirements.txt`.
3. Install Playwright browsers: `playwright install`.
4. Run the development server on port 5050 using `python main.py`.
