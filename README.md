**Encor** is a next-generation, high-performance automation platform built with modern Python (FastAPI, Playwright) and a premium, clean Web UI. It is designed to be highly efficient, reliable, and easy to use. 

*Credits: Created and maintained by [rayzuien](https://github.com/rayzien).*

## About

Encor provides a robust framework for automating browser tasks asynchronously using Playwright, while giving you a visually stunning dashboard (inspired by Meta's clean aesthetic) to monitor and manage your accounts and workflows. 

## Documentation & Guide

### Features

- ⚡ **High Performance**: Powered by asynchronous Python and Playwright.
- 🎨 **Premium UI**: Clean, responsive web interface.
- 🗄️ **Robust Data**: Built-in SQLite database management using SQLAlchemy.
- 🛡️ **Reliable Automation**: Advanced browser fingerprinting mitigation through Playwright.

### Setup Instructions

1. **Clone the repository:**
   ```bash
   git clone https://github.com/rayzien/encor.git
   cd encor
   ```

2. **Install dependencies:**
   ```bash
   pip install -r requirements.txt
   playwright install
   ```

3. **Run the application:**
   ```bash
   python main.py
   ```

4. **Access the Dashboard:**
   Open your browser and navigate to `http://localhost:5050`.
